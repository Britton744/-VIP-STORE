متجر VIP — دليل التشغيل

مهم:
- هذه نسخة تأسيسية قابلة للربط بقاعدة بيانات حقيقية.
- المنتجات الستة الظاهرة قبل إعداد Firebase أمثلة توضيحية فقط، وليست مخزوناً أو عروضاً حقيقية.
- لا توجد بوابة دفع إلكتروني أو تكامل شركة شحن مفعّل. إرسال الطلب يسجل طلباً في Firestore فقط ولا يخصم أموالاً.
- إحصائية الزيارات هي مرات تحميل صفحة المتجر، وليست عدد زوار فريدين. لا تُعرض مبيعات إلا للطلبات التي تغيّر حالتها إلى "تم التسليم" أو "مكتمل".

1) أنشئ مشروعاً في https://console.firebase.google.com
2) أضف تطبيق Web للمشروع وانسخ إعدادات Firebase.
3) افتح firebase.js واستبدل القيم النصية ببيانات مشروعك الحقيقية.
4) من Firebase Console فعّل Authentication ثم Email/Password.
5) أنشئ حساب إدارة من Authentication > Users.
6) انسخ UID الخاص بحساب الإدارة.
7) افتح Firestore Database وأنشئ قاعدة بيانات.
8) أنشئ مجموعة باسم admins، ثم مستنداً يكون معرّفه UID نفسه. يمكن أن يحتوي المستند على حقل role وقيمته admin.
9) انشر محتوى firestore.rules في تبويب Rules ثم اضغط Publish.
10) أضف منتجاتك الحقيقية من admin.html بعد تسجيل الدخول.

النشر:
- ارفع جميع الملفات مع الحفاظ على وجود index.html وadmin.html وملفات JS/CSS في المجلد نفسه.
- Netlify: اسحب مجلد المشروع بعد فك الضغط إلى صفحة النشر في Netlify أو ارفع الملفات عبر Git.
- لا تضع كلمات مرور أو مفاتيح سرية في ملفات الواجهة. إعدادات Firebase Web ليست كلمة مرور، لكن حماية البيانات تعتمد على قواعد Firestore.
- اختبر طلباً تجريبياً بنفسك قبل مشاركة رابط المتجر.

ملفات المشروع:
index.html       واجهة المتجر
admin.html       لوحة الإدارة
style.css        تصميم المتجر
admin.css        تصميم لوحة الإدارة
store.js         السلة والمنتجات والطلبات وتتبع مرات فتح الصفحة
admin.js         تسجيل الدخول والإدارة والإحصائيات
firebase.js      ربط Firebase
firestore.rules  قواعد حماية قاعدة البيانات
